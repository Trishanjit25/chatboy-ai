About Chat Boy

Your intelligent AI assistant powered by cutting-edge technology

🚀 Overview

Chat Boy is an AI-powered chatbot built with FastAPI and integrated with OpenAI API via OpenRouter. It provides intelligent, context-aware responses to any question you ask, making it your personal AI assistant.

Whether you need help with coding, writing, brainstorming, or just want to have a conversation, Chat Boy is here to assist you!

💻 Built With

🐍 Python ⚡ FastAPI 🤖 OpenAI API 🌐 OpenRouter 🎨 HTML/CSS/JS

🔌 API Endpoint

You can also use the /ai endpoint directly to get AI responses:

GET /ai?prompt=your question here

Example response format:

{"response": "Your AI response here"}

✨ Features

  • 🤖 Intelligent AI-powered responses
  • 💬 Real-time chat interface
  • 📱 Responsive design
  • 🎨 Modern dark theme with animations
  • ⌨️ Keyboard shortcuts
  • 📋 Copy messages to clipboard
